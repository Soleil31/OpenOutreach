# Проверка локаторов на сохранённых страницах

Контур, который позволяет проверить правила поиска элементов LinkedIn, не
обращаясь к самому LinkedIn. Нужен, чтобы правку селекторов можно было
доказать до выкатки, а не проверять на живом аккаунте.

## Зачем

21 августа 2026 года LinkedIn сменил вёрстку формы входа, демон перестал
находить поле пароля и ушёл в бесконечный цикл попыток входа. Проверить
исправление на живом аккаунте нельзя: каждая попытка — это трафик к площадке,
которая и так на грани блокировки.

## Как работает

`page.html` из пакета диагностики открывается через `file://`, по нему
прогоняются те же цепочки локаторов, что использует `playwright_login`.
Внешние запросы блокируются.

## Важно: страницу нужно сделать самодостаточной

**Сырой `page.html` для проверки не годится.** Стили LinkedIn лежат по внешней
ссылке на `static.licdn.com`. Без них обе копии формы (а в новой вёрстке их в
DOM две) оказываются видимыми, `.first` находит поле — и проверка выдаёт
зелёный на странице, которая в живом браузере ломала вход.

Это проверено: на сыром HTML старый, заведомо сломанный код прошёл проверку
на всех образцах. После вшивания стилей он честно упал с тем же
`No locator matched`, что и в проде.

Поэтому перед добавлением в корпус страница прогоняется через `inline_css.py`.

## Использование

```
# 1. Сделать снимок самодостаточным
curl -s -o /tmp/linkedin.css "$(grep -o 'href="[^"]*\.css[^"]*"' page.html | head -1 | cut -d'"' -f2)"
python tools/selector_verifier/inline_css.py page.html /tmp/linkedin.css corpus/login/<дата>_<описание>.html

# 2. Прогнать корпус (внутри контейнера с playwright)
python tools/selector_verifier/verify_locators.py corpus/login
```

Код возврата `0` — все обязательные элементы найдены на всех образцах.

## Корпус

`corpus/login/` — по одному образцу на версию вёрстки. Старые образцы **не
удаляются**: они и есть защита от того, что исправление под новую вёрстку
сломает работу со старой.

Снимки очищаются от персональных данных: значения полей ввода, куки и токены
в них отсутствовать обязаны. Проверять перед добавлением.
